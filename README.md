# Описание

Автоматизированный инструмент на Python для генерации синтетических отзывов и их глубокого контент-анализа с помощью искусственного интеллекта через API OpenRouter.

Программа умеет работать в двух режимах: генерировать CSV-базу отзывов с нуля с помощью LLM или анализировать уже существующий файл, формируя детальный аналитический отчет в формате JSON.

---

## Возможности

* **Интерактивный интерфейс**: выбор между генерацией новой базы данных и анализом существующего файла при запуске.
* **Синтетическая генерация**: создание реалистичных отзывов на русском языке (с разной тональностью и для разных категорий товаров) силами нейросети.
* **Глубокий анализ (Аспектный сентимент-анализ)**:
  * Определение общей тональности (positive, negative, neutral) и числовой оценки (score).
  * Выделение главной темы отзыва.
  * Поаспектный анализ (оценка качества, цены, сервиса и доставки).
  * Генерация краткого резюме (summary) и флага рекомендации.
* **Устойчивость к сбоям**: автоматическая очистка ответов LLM от Markdown-разметки (```json``` / ```csv```), обработка ошибок сети и корректная работа с кодировками (включая UTF-8 с BOM).

---

## Технологический стек

* **Язык**: Python 3.x
* **Библиотеки**: `urllib` (стандартная библиотека без сторонних зависимостей), `csv`, `json`.
* **Платформа ИИ**: OpenRouter API (по умолчанию модель `baidu/cobuddy:free`).

## Настройка и установка

1. **Сохраните код** скрипта в файл `analyzer.py`.
2. **Получите API-ключ**: зарегистрируйтесь на [OpenRouter](https://openrouter.ai/) и создайте токен.
3. **Вставьте ключ в код**: откройте `analyzer.py` и вставьте ваш токен в переменную `API_KEY`:
```python
API_KEY = "ваш_ключ_openrouter"

```



---

## Использование

Запустите скрипт через терминал:

```bash
python analyzer.py

```

### Сценарии работы:

1. **Если файла `data/reviews.csv` нет**:
Программа предложит сгенерировать его через нейросеть. После подтверждения файл запишется на диск, и скрипт автоматически начнет его анализ.
2. **Если файл `data/reviews.csv` уже существует**:
Программа спросит: использовать текущие данные или перезаписать их новыми, сгенерированными через ИИ.

Результат анализа сохраняется в `results/classified_reviews.json`. Пример структуры одной записи:

```json

  "review_text": "Экран отличный, но батарея держит всего полдня. Доставили быстро.",
  "analysis": {
    "sentiment": "neutral",
    "sentiment_score": 0.1,
    "topic": "автономность и экран",
    "aspects": {
      "quality": "positive",
      "price": "not_mentioned",
      "service": "not_mentioned",
      "delivery": "positive"
    },
    "summary": "Пользователь доволен экраном и доставкой, но разочарован временем работы от батареи.",
    "recommend": null
  }
}

```
