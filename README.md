# Описание
Автоматизированный инструмент на Python для генерации синтетических отзывов и их глубокого контент-анализа с помощью искусственного интеллекта через API OpenRouter.

Программа позволяет быстро создать базу данных отзывов или проанализировать существующую, предоставляя детальный отчет о тональности, аспектах качества и краткое резюме.

---

## 🚀 Возможности

* **Авторизация «на лету»**: При первом запуске программа запрашивает API-ключ OpenRouter и сохраняет его в локальный файл `.config.json`. Больше вводить его не потребуется.
* **Интерактивность**: Выбор между использованием вашего файла или генерацией новых данных через ИИ прямо в консоли.
* **Синтетическая генерация**: Создание реалистичных текстов на русском языке для тестирования систем аналитики.
* **Глубокий анализ (LLM-Powered)**:
    * Определение тональности (позитив/негатив/нейтрально).
    * Аспектный анализ (Качество, Цена, Сервис, Доставка).
    * Автоматическое суммаризирование отзыва.
* **Надежность**: Автоматическая очистка ответов нейросети от лишней разметки и обработка типичных ошибок API.

## 🛠 Технологический стек

* **Язык**: Python 3.x
* **Сетевое взаимодействие**: `urllib` (без внешних зависимостей).
* **ИИ Модель**: По умолчанию `baidu/cobuddy:free` (через OpenRouter).

## 📋 Формат входных данных (CSV)

Если вы используете свой файл, он должен находиться по пути `data/reviews.csv`.
Рекомендуемый формат (разделитель — запятая, кодировка UTF-8):

| Заголовок | Описание | Пример |
| --- | --- | --- |
| **ID** | Уникальный номер | `1` |
| **Товар** | Название предмета | `Ноутбук ASUS` |
| **Отзыв** | Текст отзыва | `Отличный экран, но шумят вентиляторы.` |

*Пример CSV:*

```csv
ID,Товар,Отзыв
1,Кофемашина,"Вкусный кофе, но инструкция только на китайском."

```

## ⚙️ Запуск и использование

1. **Подготовка**: Убедитесь, что у вас установлен Python 3.
2. **API Ключ**: Получите ключ на [OpenRouter](https://openrouter.ai/).
3. **Запуск**:
```bash
python analyzer.py

```


4. **Первый запуск**: Введите ключ при запросе. Он сохранится в `.config.json`.
5. **Выбор**: Следуйте инструкциям в терминале (выберите генерацию данных или анализ текущего файла).
