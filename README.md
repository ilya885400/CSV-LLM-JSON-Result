
# Описание

Автоматизированный инструмент на Python для генерации синтетических отзывов и их глубокого контент-анализа с помощью искусственного интеллекта через API OpenRouter.

Программа умеет работать в двух режимах: генерировать CSV-базу отзывов с нуля с помощью LLM или анализировать уже существующий файл, формируя детальный аналитический отчет в формате JSON.

---

## 🚀 Возможности

* **Авторизация «на лету»**: при первом запуске программа запрашивает API-ключ OpenRouter и безопасно сохраняет его в локальный файл конфигурации. Больше ключ вводить не придется.
* **Интерактивный интерфейс**: удобный выбор между генерацией новой базы данных и анализом существующего файла прямо в терминале.
* **Синтетическая генерация**: создание реалистичных отзывов на русском языке (с разной тональностью и для разных категорий товаров) силами нейросети.
* **Глубокий анализ (Аспектный сентимент-анализ)**:
* Определение общей тональности (positive, negative, neutral) и числовой оценки (score).
* Выделение главной темы отзыва.
* Поаспектный анализ (оценка качества, цены, сервиса и доставки).
* Генерация краткого резюме (summary) и флага рекомендации.


* **Устойчивость к сбоям**: автоматическая очистка ответов LLM от Markdown-разметки (````json` / ````csv`), обработка ошибок сети и корректная работа с кодировками (включая UTF-8 с BOM).

---

## 🛠 Технологический стек

* **Язык**: Python 3.x
* **Библиотеки**: `urllib` (стандартная библиотека для работы с сетью без сторонних зависимостей вроде `requests`), `csv`, `json`.
* **Платформа ИИ**: OpenRouter API (по умолчанию используется бесплатная модель `baidu/cobuddy:free`).

## ⚙️ Настройка и установка

1. **Клонируйте репозиторий** или сохраните код скрипта в файл `analyzer.py`.
2. **Получите API-ключ**: зарегистрируйтесь на [OpenRouter](https://openrouter.ai/) и создайте токен (ключ должен начинаться с `sk-or-...`).

---

## 📋 Использование

Запустите скрипт через терминал:

```bash
python analyzer.py

```

### Сценарии работы:

1. **Первый запуск**:
Программа сообщит, что ключ не найден, и попросит ввести ваш API-токен OpenRouter. После успешного ввода ключ сохранится в файл `.config.json` в корневой папке проекта.
2. **Если файла `data/reviews.csv` нет**:
Программа предложит сгенерировать его структуру и наполнение через нейросеть. После подтверждения файл запишется на диск, и скрипт автоматически начнет его анализ.
3. **Если файл `data/reviews.csv` уже существует**:
Программа спросит: использовать текущие данные или перезаписать их новыми, сгенерированными через ИИ.

> **Совет:** Если вам нужно изменить API-ключ, просто удалите созданный файл `.config.json` или отредактируйте его вручную.

## 📊 Формат выходных данных

Результат анализа сохраняется в `results/classified_reviews.json`. Пример структуры одной записи в отчете:

```json
{
  "id": "1",
  "product": "Смартфон Икс",
  "review_text": "Экран отличный, но батарея держит всего полдня. Доставили быстро.",
  "analysis": {
    "sentiment": "neutral",
    "sentiment_score": 0.1,
    "topic": "автономность и экран",
    "aspects": {
      "quality": "positive",
      "price": "not_mentioned",
      "service": "not_mentioned",
      "delivery": "positive"
    },
    "summary": "Пользователь доволен экраном и доставкой, но разочарован временем работы от батареи.",
    "recommend": null
  }
}

```
